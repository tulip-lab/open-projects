# `NEXUS` Quantum Machine Learning

---
- Project Supervisor :point_right: : [Baobao Song](https://www.tulip.academy/members/)
- Prepared by :tulip: **[TULIP Lab](https://www.tulip.academy/members)**
---

Quantum machine learning explores how quantum computational models can be used for learning tasks and how machine learning can support the study of quantum systems. This project provides a starting point for investigating quantum representations, quantum learning models, and comparisons with classical approaches.

The detailed research question, datasets, computational resources, and stage-specific tasks should be agreed with the project supervisor. The Stage :one: brief is pending content verification.
